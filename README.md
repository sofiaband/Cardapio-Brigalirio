# Cardápio Digital — Brigalírio

Site estático e responsivo do cardápio da Brigalírio, preparado para publicação gratuita no GitHub Pages.

## Recursos

- Catálogo com nove sabores
- Busca por nome ou descrição
- Tabela de preços por quantidade
- Botões de pedido para o WhatsApp
- Mensagens preenchidas automaticamente
- Avaliação por estrelas enviada pelo WhatsApp
- Visual para celular e computador

## Arquivos

- index.html: contém todo o HTML, CSS e JavaScript do site
- README.md: instruções do projeto
- .nojekyll: garante a publicação correta no GitHub Pages

## Como publicar

1. Entre em https://github.com e clique em New repository.
2. Use o nome cardapio-brigalirio.
3. Selecione Public e clique em Create repository.
4. Escolha uploading an existing file.
5. Envie index.html, README.md e .nojekyll.
6. Clique em Commit changes.
7. Abra Settings, depois Pages.
8. Em Source, escolha Deploy from a branch.
9. Selecione a branch main, a pasta /(root) e clique em Save.

O endereço ficará no formato:
https://SEU-USUARIO.github.io/cardapio-brigalirio/

## Onde alterar o site

- WhatsApp: procure por WHATSAPP_NUMBER em index.html.
- Sabores: procure por const products.
- Valores: procure por Valores por quantidade.
- Instagram: procure por instagram.com/brigalirio.
- Cores: procure por :root no início do CSS.
